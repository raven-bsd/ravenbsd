## Limits

* P2e (procd) and P3 (tty/ptyd) are not merged into this base. Their rows are waived here, not
  claimed as passing; a later merge can replace the waivers with the procd/tty Qtests.
* P2k exec is static single-threaded image replacement (1 MiB copy cap; no `PT_INTERP`).
* P2l priority exposes `SCHED_OTHER` only; `SCHED_FIFO`/`SCHED_RR` return `ENOTSUP`. A user
  thread already queued keeps its slot until the next enqueue/wake.
* No board claim.
