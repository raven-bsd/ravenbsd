# P5 - filesystem POSIX semantics

This note records the P5 implementation, the executable evidence, and the rows that remain
partial. The machine-readable claims live in `docs/posix/evidence/P5.toml`; the generated
profile, trace and gate report are `docs/posix/profile.toml`, `docs/posix/traceability.toml`
and `docs/posix/CONFORMANCE.md`.

## Implemented surface

The VFS control protocol (`raven-proto-fs`) gained:

* `LINK`, `CHOWN`, `LCHOWN`, `FCHOWN`, `MKFIFO`, `MKNOD`, `UTIMENS`, `STATVFS` and `LSTAT`;
* the fixed `StatVfs` response record and a `Stat` response for `LSTAT`;
* whole-second `UTIME_NOW`/`UTIME_OMIT` selectors and `ID_NO_CHANGE` for ownership.

`ramfsd` and `raven-ramfs-core` now support hard links with real `nlink`, `chown`/`lchown`/
`fchown`, FIFO/device/socket nodes, `utimensat`, and `statvfs`. `fsd-ufs` exposes the same
operations on top of `ufs-core`, whose namespace layer gained a `mknod` creation path.
`vfsd` routes all of them, rejects cross-mount hard links with `EXDEV`, and uses a new `LSTAT`
call for unlink/rename permission checks so a dangling symlink can still be removed.
`raven-vfs-core` gained the `same_mount` helper used by the link path.

## Remaining defects

* **mmap-file**: kernel file-backed mappings are outside the P5 owns; no qtest maps a file and
  observes private/shared updates. The row stays `partial` with the kernel file as evidence.
* **record-lock**: there is no `fcntl(F_GETLK/F_SETLK/F_SETLKW)` path, no lock owner in the
  process model, and no close-on-exec interaction. The row stays `missing`; a protocol-only
  lock table would not be POSIX.
* **sparse-file**: UFS extension is hole-backed, but ramfs zero-fills a `Vec` and counts every
  byte in `st_blocks`. A row-level claim would hide the ramfs divergence, so it stays `missing`.
* **umask**: `spec/user-management/U3-kernel-identity.md` records that umask remains a
  libc/session value; the VFS create protocol still sends a fixed mode.

## Scope notes

The directive explicitly added the missing protocol calls to P5. The implementation therefore
touches `crates/raven-proto-fs`, `crates/ufs-core`, `libc/ravenlibc` response matches,
`userland/rt` response matches, the k55 UFS probe and the `fsd-ufs-rw` case, plus the generated
POSIX profile/trace/GAPS/CONFORMANCE files. These are recorded as necessary deviations: the
VFS-level behaviour cannot be claimed without the wire calls and without regenerating the
gate's trace entries.
