Statuses are assigned only from the commands above:

* **PROVEN** - a named test in `test` ran on this tree and its assertions cover the stated
  contract. For a syscall row this is the syscall's stated ABI/error contract, not every positive
  behaviour; the positive behaviour lives in the area rows.
* **PARTIAL** - the positive side or the error side is proven, but not both, or the probe is
  narrower than the contract.
* **UNTESTED** - implementation exists and was read, but no test on this tree proves it.
* **MISSING** - no implementation was found.
* **SUSPECT** - code reading shows a concrete defect at `file:function:line`; the row names the
  test that settles it. A suspect is not a finding until that test fails.

Counts are the literal sum of `docs/kernel/audit/gaps.tsv`:

```text
237 rows: PROVEN 139 / PARTIAL 47 / UNTESTED 49 / MISSING 1 / SUSPECT 1
```

The register is authoritative for every count in this document. A PROVEN syscall row is evidence
for its stated error/ABI contract only; the report does not claim that every positive path of
every syscall is proven.

## 7. Findings outside the register (test and repository defects)

1. **raven-spawn no-alloc build** - SUSPECT. `crates/raven-spawn/src/lib.rs:730`, `:1603`, `:1605`
   use `alloc_crate` while the alias is gated by `feature = "alloc"`. `sh
   tests/fixtures/s36-lifecycle/build.sh` exits 101, blocking `process-lifecycle`, `driver-mmio`,
   `driver-dma` and `driver-irq`. Proposed: gate the alloc-only helpers on the feature or enable
   the feature in those fixtures.
2. **ABI table drift** - `tests/abi/abi-v1.txt` lacks `SYSCALL 0x0d PROC_CHROOT` and
   `SYSCALL 0x46 PROC_REBOOT`; `abi-diff` fails. Proposed: regenerate the table.
3. **kick-eintr fixture** - `tests/qtest/cases/kick-eintr-fixture/src/main.rs:163` dups a thread
   handle that `crates/raven-spawn/src/lib.rs:903-907` already closed (EBADF). This is a fixture
   defect, not a kernel finding; the EINTR contract stays UNTESTED.
4. **Prompt-prefixed expectations** - `vfsd` and `ls-dirent` complete their work but miss
   anchored expectations such as `^svcd: all services up$` because the first output line starts
   after the `raven# ` prompt. The audit records PARTIAL/PARTIAL rather than rewriting the cases.
5. **evq crash** - `evq` exits 1 with `evq: crash` and an empty serial log. The cause is UNKNOWN
   (no panic line); the register marks the event-queue wait contract PARTIAL and the hammer list
   names the re-run with serial capture. No cause is guessed.
6. **stat-fs image** - the case cannot build because `build/ssh/x86_64/bin/sshd` is absent in this
   clone; the contract stays UNTESTED rather than being counted as a product failure.

## 8. Provenance

All audit artifacts are original analysis. NetBSD is read as the literal donor for the named
contracts; FreeBSD and Linux are read for outcome only; Illumos turnstile/DTrace are CDDL and were
read for behaviour only. No donor code was copied, transcribed or paraphrased into this document
or the two Python checks. The checks use only the Python standard library and read the product
tree; they do not modify it.
