# Native syscall ABI (v1 freeze)

Status: OBSERVED on `lance/S74`. The native ABI is frozen for the 0.2.0 stability claim. The
machine-readable table is **generated** from `crates/raven-abi` by `tools/abi-diff` (never a
hand-edited copy) and committed as `tests/abi/abi-v1.txt`. `scripts/abi-diff.sh --self-test`
re-generates and compares; `scripts/abi-diff.sh BASE..HEAD` prints what changed between two
revisions and exits non-zero on a removal or layout change unless a commit in the range carries
`abi-accepted: <reason>`.

## Stability labels

| Label | Meaning |
|---|---|
| `Committed` | Frozen for v1; the number, name and layout will not change without an `abi-accepted` change. |
| `Evolving` | Documented but still in development; may change in a later release. |
| `Private` | Kernel/driver internal (debug console, device access, tracing); not a stable userspace contract. |

`MContext` is architecture-conditional (256 / 4384 / 784 bytes for x86-64 / aarch64 / riscv64); the
table records the first (x86-64) layout.

## Diff and acceptance rule

A removal of a syscall/struct, a syscall renumber, or a struct layout change is a **breaking**
change: `scripts/abi-diff.sh BASE..HEAD` exits non-zero. Such a change may only land with a commit
whose message carries `abi-accepted: <reason>`. Additions are always allowed and exit zero.
