## Gate definition

The SSH gate is green only when all of the following hold:

1. **10/10** `ssh ... ls` attempts exit **0** within **5000 ms**, returning the exact marker bytes
   (S7). A run that returns the bytes but is killed at 30 s is **not** a pass.
2. **Wrong password refused**: client exit **255** with `Permission denied` (S3).
3. **PTY**: `ssh -tt ... tty` returns `/dev/pts/N` (S8).

All S0-S8 rows must pass with their exact assertions, and all K1-K6 kernel-contract rows must
pass. The current gate is **RED**: S7 and S8 are red; S3 and K1-K6 are green.

## Open gaps and caveats

1. **S7 (red):** bytes and routing are exact; all ten attempts exit -9 at ~30 s instead of 0
   within 5 s. Owner K443 (SIGCHLD/ppoll/waitpid); K434 records the rerun. K440's later partial
   run saw 4/10 exact markers, still exit -9; both are red.
2. **S5-session (red):** no EPIPE, exit -9 at 15 s, peer `ESTAB`; the server-side session close is
   the same family as S7-exit. Owner K443; K434 observes.
3. **S8 (red):** `pty-alloc` passes but `ssh -tt ... tty` still returns
   `PTY allocation request failed on channel 0`. K442 merged the privsep exchange and pty inode
   identity; K434 rev 24 is rerunning S8 on `314a225d`, and K444 owns the termios round-trip.
4. **K1-K6 green is on `origin/kevin/K440` `f2c1ef7e`, not master.** K440 is PARTIAL and not
   merged; the board must not read the suite as merged-tree evidence until it lands.
5. **S1 literal:** the measured banner is `SSH-2.0-OpenSSH_10.6`, which is the `SSH_VERSION`
   string in `addons/ssh/openssh/version.h:3`. The K434 ticket's `10.6p2` is the portable release
   string. K434 should align the ticket literal; the measured row itself is exact.
6. **S3 peer address:** the server log records `from UNKNOWN port 65535 ssh2`; the expectation is
   `Accepted password for raven`, which is met, but the peer-address field is unresolved.
7. **S6 length:** the client log records type 91 and the channel-confirm text, not the 44-byte
   packet length. The row is marked PASS on the recorded fields; K434 should record the length to
   fully satisfy the assertion.
8. **K442 external gate:** K442's guest PTY exchange is green, but its clone's external
   `ssh -tt` attempt was blocked by K195 staging (`sshd` never started in that image). This is not
   an S8 pass.
9. **No new measurement:** this document only reorganises the cited measured rows. It does not run
   QEMU or SSH.
