# Pi 4 E-Ink board evidence

Status: **NO BOARD EVIDENCE.** This document is the owner procedure for K385/E5. No Pi 4 board,
panel, serial transcript or photo has been captured. The host checks below run without hardware;
they do not claim a board result.

## What the owner must capture

| Field | Required value | Artifact |
|---|---|---|
| Board | physical Pi 4 with the 7.5" E-Ink panel | owner attestation |
| Image | built `pi4-release` image | `build/aarch64/ravenbsd-pi4.img` + SHA-256 |
| Serial transcript | bounded UART capture with the Pi 4 board marker | `build/pi4/eink.serial.log` + SHA-256 |
| Photo | real photo of the running panel | photo file + SHA-256 |
| Panel | panel SKU/model | evidence file |
| Fetch URL | content URL displayed by the panel | evidence file |
| NTP time | ISO8601 UTC time after NTP sync | evidence file |
| Refresh | refresh interval in seconds (positive) | evidence file |
| Attestation | owner confirms board/photo/serial are physical | evidence file (PENDING until signed) |

## Host checks (no serial port, no board claim)

```sh
timeout 60 sh -n scripts/pi4-eink-evidence.sh
timeout 60 sh scripts/pi4-eink-evidence.sh --check
timeout 60 sh scripts/pi4-eink-evidence.sh --dry-run
```

`--check` validates this document, `tests/evidence/pi4-eink/README.md`, the board checker and the
capture script. `--dry-run` prints the exact board command. Neither opens a serial device or writes
an evidence file.

## Board command

```sh
sh scripts/pi4-eink-evidence.sh \
  --serial /dev/ttyUSB0 \
  --log build/pi4/eink.serial.log \
  --duration 120 \
  --image build/aarch64/ravenbsd-pi4.img \
  --photo board-eink.jpg \
  --panel '<panel SKU>' \
  --url 'https://<host>/<content>' \
  --ntp '<YYYY-MM-DDTHH:MM:SSZ>' \
  --refresh 60 \
  --out tests/evidence/pi4-eink/evidence.md
```

The serial capture is bounded by `--duration` (default 120 s). The evidence file is written only
when every field is present; the photo and serial SHA-256 values are recorded. The file ends with
the owner attestation **PENDING**; the owner must sign it before the E5 release gate consumes it.

## Refusal rules

The command reuses `scripts/board-pi4-check.sh`'s rule and exits 2 for:

* a serial log or photo containing a QEMU/tcg/emulator marker;
* a header marking the capture as virt/virtual/synthetic/fixture/sample;
* a log without a Pi 4 board marker (`bcm2711`/`raspi4b`/`raspberry pi 4`);
* a missing photo, panel, URL, NTP time, refresh seconds, image or serial log;
* an invalid URL, NTP timestamp or non-positive refresh interval.

A missing field is an error, not a default. A host check, a QEMU run or a synthetic log is not a
board result.

## Evidence file

Default: `tests/evidence/pi4-eink/evidence.md`, with the image/serial/photo hashes, panel SKU,
fetch URL, NTP time, refresh interval and owner-attestation line. The directory also carries
`README.md`; no board evidence file exists until the owner runs the board command.
