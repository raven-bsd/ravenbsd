## Definition of green

0.1.0 can be tagged only when all of the following hold on one master commit:

1. `cargo xtask posix-check --profile posix --arch x86_64` is green with the generated
   `CONFORMANCE.md` naming that commit, and `posix-gaps --check` exits 0.
2. `make check` exits 0, including `clippy user programs x86_64`, provenance and all host tests.
3. `cargo run -q -p libc-gate -- verdict` exits 0.
4. `sh scripts/kernel-gate.sh` exits 0 and `docs/kernel-gate.md` names that commit.
5. `release-login`, `posix-shell`, `libc-spawn-std`, `libc-spawn-cmd`,
   `tests/release/check-release.sh`, `tests/release/check-inventory.sh` and
   `scripts/release.sh --check` are green on that commit.
6. `dynamic-userland` (x86_64) and `dynamic-exec-aarch64` pass.
7. A Pi 4 serial transcript passes `check-transcript.sh` and every GENET marker is present in a
   board log.

Until then: **NO-GO**, no tag, no POSIX claim, Pi 4 **UNVERIFIED**, 24 h soak **NOT executed**.
Dynamic aarch64 and K97 are open.
