# POSIX interface extension list (the P1f7 waiver list).
#
# Each name is a present profile interface row that is a non-POSIX or extension-only symbol and
# does not compile under the POSIX gate feature macros on either architecture. The committed
# interface sweep reports these rows as EXTENSION and does not fail on them. A failure for a name
# not in this list is a required-declaration regression and fails the sweep.
#
# Classification source: absent from the Open Group Issue 8 XSH function index
# (https://pubs.opengroup.org/onlinepubs/9799919799/idx/functions.html) or an extension family:
# BSD/legacy (brk, eaccess, euidaccess, getpagesize, getpeereid, lchmod, lutimes, sethostname, timegm),
# Linux (getdents, madvise, mlock2, preadv2, pwritev2, renameat2, syncfs),
# LFS *_64 aliases, stdio *_unlocked/getw/putw/setbuffer/setlinebuf, C11 strfrom*, and the
# removed/obsolescent stime/usleep/cuserid/timespec_getres.
